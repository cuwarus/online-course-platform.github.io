# CourseHub — Платформа онлайн-курсов (Micro-SaaS)

## 📖 Описание
Полноценная платформа для продажи коротких видеокурсов. Это **не просто одностраничник**, а многосекционный сайт с:

- ✅ **6 секциями**: Курсы, Инструкторы, Отзывы, FAQ, Тарифы, CTA
- ✅ **Адаптивность**: идеально работает на iPhone, Android, iPad, десктопах
- ✅ **Анимации**: плавное появление при скролле, hover-эффекты, floating cards
- ✅ **Интерактивность**: раскрывающийся FAQ, мобильное бургер-меню, счётчики
- ✅ **8 готовых курсов**: реальные фото, рейтинги, число студентов, длительность
- ✅ **4 секции доверия**: инструкторы, отзывы, статистика, гарантия
- ✅ **Монетизация**: подписка Free/Pro/Team + продажа отдельных курсов

---

## 🚀 Как запустить

### Локально
```bash
# 1. Скачайте архив online-course-platform.zip
# 2. Распакуйте в любую папку
# 3. Откройте index.html в браузере

# Или запустите локальный сервер:
python -m http.server 8000
# Откройте http://localhost:8000
```

### Для продакшена
Загрузите на любой статический хостинг:
- **GitHub Pages** — бесплатно
- **Netlify** — бесплатно + автодеплой
- **Vercel** — бесплатно + CDN
- **Cloudflare Pages** — бесплатно

1. **Header** — логотип, навигация, кнопка регистрации
